# Maintaining

The code in `plugin/` is a copy of the Context Pit Crew mod from the author's private source repository (folder `mods/context-pit-crew` there). Changes are made there first and copied here; this repository holds only Context Pit Crew. To refresh the copy, run `rsync -a --delete --exclude .DS_Store "$SOURCE/mods/context-pit-crew/" plugin/` from this repository's root, with `SOURCE` set to your checkout of the source repository. Because `--delete` makes `plugin/` match the source exactly, read `git diff plugin/` before anything else: if it takes back a change made here first (the version number, or wording changed for this public copy), the source has not caught up yet, so restore those hunks with `git checkout -p plugin/` and make the same change in the source. Then do four things before committing. Make sure `version` is the same in `plugin/.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json`, and add a line to the README's changelog. Run `claude plugin validate plugin`, `claude plugin test plugin` and `claude plugin validate .` with the Claude Code build that runs the mod. Last, read `git diff` for personal paths, names or notes in code comments and test fixtures as well as in the docs, because this repository is public.
